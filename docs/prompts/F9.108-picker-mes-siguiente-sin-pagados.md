### 2.1 Hallazgo bloqueante (arreglar en este spec)

`Comprobantes.tsx:467-480` — rama *"esperado sin obligación abierta"* de `handleConciliar()`: arma el payload con `...preloadBase` y llama a `cargarMovimientoDesdeComprobante`.

El callable valida en `functions/src/index.ts:1756-1770`:

- `creadoPor !== callerMemberId` → `permission-denied` · **`preloadBase` no tiene `creadoPor`** (`Comprobantes.tsx:330-357`)
- `typeof monto !== 'number'` → `invalid-argument` · **`preloadBase.monto` es `String(...)`**
- `typeof fechaMs !== 'number'` → `invalid-argument` · **no existe `fechaMs`**
- `mes` con formato `^\d{4}-\d{2}$` → `invalid-argument` · **no existe `mes`**

⇒ **Esa rama falla siempre, hoy, en producción.** Y es justamente la rama que más va a pegar con el mes siguiente (un esperado de agosto normalmente todavía no tiene obligación creada). El único lugar que arma el payload válido es `AltaMovimiento.tsx:210-238` (incluye `creadoPor`, `fechaMs`, `mes` y resuelve TC para USD). Se deriva ahí en vez de duplicar la lógica.

Agregar (sin tocar nada existente — `Resumen.tsx` / Card HOY consumen este módulo y **no deben cambiar de comportamiento**):

```ts
// F9.108 — grupo de agenda con su mes, para el picker de conciliación multi-mes.
export type GrupoAgenda = { mes: string; entradas: AgendaEntry[] };

// F9.108 — candidatos del picker: los cubiertos (pagado/automático/confirmado) NO se ofrecen
// más, ni grises. Orden: vencidos primero, después por día de vencimiento ascendente.
export function pendientesOrdenados(entradas: AgendaEntry[]): AgendaEntry[] {
  return entradas
    .filter(e => !agendaCubierto(e))
    .slice()
    .sort((a, b) => {
      const aVenc = a.kind === 'esperado' && a.ci.estado === 'vencido' ? 0 : 1;
      const bVenc = b.kind === 'esperado' && b.ci.estado === 'vencido' ? 0 : 1;
      if (aVenc !== bVenc) return aVenc - bVenc;
      return diaDeAgenda(a) - diaDeAgenda(b);
    });
}
```

```ts
function parsePickerSel(sel: string): { kind: 'esperado' | 'suelto' | null; mes: string; id: string } {
  if (sel.startsWith('esperado:')) {
    const resto = sel.slice('esperado:'.length);
    const i = resto.indexOf(':');
    return { kind: 'esperado', mes: resto.slice(0, i), id: resto.slice(i + 1) };
  }
  if (sel.startsWith('suelto:')) return { kind: 'suelto', mes: '', id: sel.slice('suelto:'.length) };
  return { kind: null, mes: '', id: '' };
}
```
