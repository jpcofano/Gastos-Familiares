## §2 F9.194 — Dos prompts

**Motivo:** un solo prompt pedía mercado + política + oportunidades + sectorial + agenda + 15
posiciones con 15 búsquedas. Las posiciones llegaban al final con el presupuesto agotado, y el
largo empujaba al corte con "seguí".

**Parte 1 — Estrategia** (`buildPromptEstrategiaV3`, contexto `contextoInformeV3`, `parte: 'estrategia'`):

- Devuelve global (con coherencia), oportunidades (con lista blanca, 300 palabras), sectorial y agenda.
- El sectorial sube a 150 palabras por driver porque ahora alimenta la parte 2.
- Las 15 búsquedas van a drivers, mercado faltante, agenda y datos de candidatos.

**Parte 2 — Posiciones** (`buildPromptPosicionesV3`, contexto `contextoPosicionesV3`, `parte: 'posiciones'`):

- Recibe `panorama`: diagnóstico, sectorial y agenda que dejó la parte 1, leídos frescos de Firestore.
- Cada posición trae su `factor`, junto con los desvíos de política por posición.
- Las 15 búsquedas son para las posiciones; el panorama no se repite.
- Fichas de hasta 130 palabras, coherentes con el sectorial de su driver (si algo lo contradice, se dice).
- Si la parte 1 no se importó, el prompt lo avisa.

**Server:**

- `buildPromptV3` despacha por `contexto.parte`.
- El import de modo `completo` importa cada sección **solo si vino**: una sección ausente ya no es
  error.
- Las `notas` de la parte 2 se cuelgan del último doc de `analisisGlobal`.

**UI:**

- "Actualización integral" tiene dos botones, **Chat 1 · Estrategia** y **Chat 2 · Posiciones**, a
  usar en ese orden.
- El modal se titula "Informe 1/2" o "Informe 2/2".

## §3 `jsonrepair`: no se agrega

No hace falta, y Juan pidió agregarlo solo si era necesario. Con dos prompts cada respuesta es
bastante más corta: la parte 1 pide 4 secciones y la parte 2, fichas sin panorama. Además:

- Las dos partes piden un único bloque JSON completo y dicen qué acortar si falta espacio.
- `extraerJson` une bloques partidos (F9.191).

Si un JSON llega roto igual, el import falla de forma visible y se repite solo esa parte. Reparar
JSON a ciegas podría guardar una sección truncada como si estuviera completa, y eso es peor que un
error visible.
