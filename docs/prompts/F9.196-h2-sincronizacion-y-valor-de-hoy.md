## Reglas para el código de producción

- **Lista blanca en producción, igual que en exploración.**
  - PPI: las rutas de §0 más `Configuration/*` de consulta.
  - Bitfinex: solo `auth/r/*`.

  Cualquier otra ruta tira error antes de salir, con test. `Order/*` y `auth/w/*` no existen para
  este código.
- **Credenciales en producción: solo secretos de Firebase**, con `defineSecret`, igual que
  `ANTHROPIC_API_KEY` en `functions/src/index.ts`:
  - PPI: `PPI_API_KEY`, `PPI_API_SECRET`, `PPI_AUTHORIZED_CLIENT`, `PPI_CLIENT_KEY` y
    `PPI_ACCOUNT_NUMBER`;
  - Bitfinex: `BITFINEX_API_KEY` y `BITFINEX_API_SECRET`.

  El `.env` de OneDrive sigue sirviendo solo para los scripts locales.
- **Nunca se loguean** headers, tokens, firmas ni nonces. Los errores llevan ruta, status y cuerpo,
  con los tokens tapados.
- **Código compartido.** `functions/` no puede importar de `src/` (`rootDir: src`). El cron necesita
  `armarCarteraViva`, `resolverTcCarteraViva` y la lógica de movimientos y flujos.
  - Seguí el precedente de `normalizador.ts`: una copia idéntica en `functions/src/` y un script,
    `scripts/verificarCopiasIdenticas.ts`, que falla si las copias difieren byte a byte.
  - El original sigue en `src/datos/`. No mantengas dos versiones distintas.
- **Reloj de PPI:**
  - el token dura 8 horas: se cachea en memoria de la instancia;
  - el refresh lleva el token anterior en el header;
  - un 400 en el login se trata como credenciales inválidas: la doc dice 401, la realidad es 400.
- **Nonce de Bitfinex en milisegundos**, sin cambiarlo nunca.
- **Idempotencia:** volver a correr la sincronización el mismo día no duplica nada. Los
  movimientos se guardan con ids deterministas.

## Deploy (lo hace Juan, no Code)

1. Cargar los secretos, uno por vez. Cada comando pide el valor en la terminal:
   ```
   firebase functions:secrets:set PPI_API_KEY
   firebase functions:secrets:set PPI_API_SECRET
   firebase functions:secrets:set PPI_AUTHORIZED_CLIENT
   firebase functions:secrets:set PPI_CLIENT_KEY
   firebase functions:secrets:set PPI_ACCOUNT_NUMBER
   firebase functions:secrets:set BITFINEX_API_KEY
   firebase functions:secrets:set BITFINEX_API_SECRET
   ```
2. Hacer el deploy en este orden: `firebase deploy --only firestore:rules,firestore:indexes`,
   después `functions` y después `hosting`.
3. **Las callables nuevas** ("Sincronizar PPI ahora" y la de Bitfinex) necesitan el permiso de
   Cloud Run, con `gcloud run services add-iam-policy-binding <servicio> --member=allUsers
   --role=roles/run.invoker`. Si no, el botón falla sin explicación.
