## Permisos de Cloud Run (solo si faltan)

No hay funciones nuevas. Pero un deploy que recrea un servicio puede resetear el binding
`allUsers → roles/run.invoker`. Sin él, la callable devuelve `internal` sin logs de ejecución, y la
app ahora lo muestra como "No respondió la función…".

Para comprobarlo en las 3 callables de F9.196 (tiene que aparecer `allUsers` con
`roles/run.invoker`):

```
gcloud run services get-iam-policy sincronizarppiahora --region southamerica-east1 --project gastos-familiares-e6415
gcloud run services get-iam-policy sincronizarbitfinexahora --region southamerica-east1 --project gastos-familiares-e6415
gcloud run services get-iam-policy recalcularcarteraviva --region southamerica-east1 --project gastos-familiares-e6415
```

Si a alguna le falta:

```
gcloud run services add-iam-policy-binding sincronizarppiahora --region southamerica-east1 --project gastos-familiares-e6415 --member=allUsers --role=roles/run.invoker
gcloud run services add-iam-policy-binding sincronizarbitfinexahora --region southamerica-east1 --project gastos-familiares-e6415 --member=allUsers --role=roles/run.invoker
gcloud run services add-iam-policy-binding recalcularcarteraviva --region southamerica-east1 --project gastos-familiares-e6415 --member=allUsers --role=roles/run.invoker
```

En Cloud Run, los servicios de las Functions v2 llevan el nombre de la función en minúsculas. Si
`get-iam-policy` dice que el servicio no existe, buscá el nombre con:

```
gcloud run services list --region southamerica-east1 --project gastos-familiares-e6415
```

## Pruebas en la app, en orden

1. **Ctrl+F5**, para traer el hosting nuevo.
2. **"Calcular valor de hoy"** (o "Recalcular"). Si falla, tiene que mostrar el mensaje real. Por
   ejemplo:
   - "no hay una corrida vigente…";
   - "No respondió la función…" si es un `internal` sin texto.
   
   Nunca "Valor de hoy calculado".
3. **Los tres botones en los dos heroes:** "Sincronizar PPI ahora", "Sincronizar Bitfinex ahora" y
   "Recalcular" o "Calcular valor de hoy". Tienen que estar también en el hero de la corrida, cuando
   todavía no hay valor de hoy.
4. **Sincronizar PPI y sincronizar Bitfinex.**
   - El toast dice cuántas posiciones y movimientos trajo.
   - Si la cartera falla, dice "sincronizado, pero no se pudo calcular el valor de hoy: …".
   - Dos toques seguidos a Bitfinex: el segundo responde "Ya hay una sincronización de Bitfinex
     corriendo…".
5. **Subir un "Mis Instrumentos" nuevo de la 402665, en dólares.**
   - La vista previa dice "Archivo en dólares (detectado…)".
   - El aviso de lo guardado inflado aparece, porque hoy está guardado el de pesos del 21/10 leído
     como dólares.
   - Al confirmar, la 402665 queda bien y se borran los movimientos inferidos inflados.
6. **"Para decidir" → "Aplicar"** (Configuración).
   - Lo anterior al 21/10 sin par pasa a historial.
   - Si la cartera falla, lo dice; no dice "Aplicado".
7. **`npx tsx scripts/listarBalanzInflados.ts`.** Necesita la service account en
   `secrets\serviceAccountKey.json` y solo lee. Después del punto 5 tiene que decir que ninguna
   cuenta viva de Balanz está inflada.
