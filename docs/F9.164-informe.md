**La causa es una contradicción que el prompt arrastra desde F6.5**, y no la introdujo este cambio:

```

```

Esa regla le dice al modelo que lo emita **como línea**. El bloque de `ajustesConsolidado` le dice
que lo emita **como ajuste**. Ninguna de las dos dice "y no la otra", así que el modelo resuelve la
contradicción de una forma u otra según la corrida.

como línea en 11 de 11 — pero eso era la moneda cayendo del mismo lado once veces, no una regla.

**No lo arreglé**, por dos razones: la spec dice que si alguno no cuadra lo reporte y no lo cierre; y
tocar la regla 1189 en el mismo commit que el arreglo de `pagosDelPeriodo` volvería inatribuible cuál
de los dos movió cada número — que es el criterio que viene ordenando todo este hilo.
